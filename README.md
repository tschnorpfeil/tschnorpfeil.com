# tschnorpfeil.com

Personal website of Tobias Schnorpfeil — engineer & entrepreneur.
Live at [tschnorpfeil.com](https://tschnorpfeil.com/) (EN) and [tschnorpfeil.com/de/](https://tschnorpfeil.com/de/) (DE).

## Stack

- Single-file static HTML/CSS/JS, no build step, no runtime dependencies
- Self-hosted Geist font family (GDPR-friendly, no CDN)
- Hosted on GitHub Pages with a custom domain

## SEO / GEO

- Bilingual via dedicated URLs (`/` EN, `/de/` DE) with `hreflang` + `x-default`
- Schema.org JSON-LD (`Person` + `WebSite` graph) on both versions
- Open Graph, Twitter Cards, canonical URLs, sitemap with hreflang annotations
- `llms.txt` and explicit AI-crawler rules in `robots.txt`
